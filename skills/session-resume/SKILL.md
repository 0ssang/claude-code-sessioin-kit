# 세션 맥락 복원

!`bash "__KIT_DIR__/mem.sh" overview 2>&1 || true`

## 절차
1. **최신성 확인** — 인계 노트보다 최근의 `*-compact-*.md` 스냅샷이 있으면 노트 저장 뒤에도 작업이 이어졌다는 뜻이다. 그 스냅샷(`.claude-memory/snapshots/`)을 읽어 반영한다.
2. **실제 상태와 대조** — 노트를 그대로 믿지 말고 확인한다: 언급된 파일이 있고 설명과 맞는지, git 저장소면 `git status`와 `git diff --stat`, 노트가 "실패 중"이라 한 테스트가 여전히 실패하는지(빠를 때만).
3. **필요한 만큼만 읽기** — 다음 작업에 필요한 파일만 읽는다.
4. **브리핑** (10줄 이내): 현재 위치 · 마지막으로 한 일 · 노트와 실제 상태의 차이 · 미해결 질문과 블로커 · 다음 행동
5. 사용자에게 진행할지 묻는다.
