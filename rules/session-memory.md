# 세션 메모리 규칙

대화 컨텍스트는 `/clear`나 압축으로 사라진다. 다음 세션에 남아야 하는 것은 프로젝트의 `.claude-memory/`에 쓴다.
이 폴더가 있는 프로젝트에서만 세션 훅이 동작한다.

| 파일 | 용도 | 갱신 |
|---|---|---|
| `handoff.md` | 다음 세션을 위한 인계 노트 | `/session-save` |
| `progress.md` | 시간순 작업 로그 | 의미 있는 작업 단위를 끝낼 때마다 Claude가 추가 |
| `decisions.md` | 결정 기록 | 기술 선택, 트레이드오프, 사용자가 내린 결정 |
| `snapshots/` | 압축 직전 자동 스냅샷 | PreCompact 훅 (자동) |
| `session-log.md` | 세션 종료 기록 | SessionEnd 훅 (자동) |

## 행동 규칙
- 세션 시작, `/clear`, 압축 직후에 주입되는 "이전 세션 맥락"을 기준으로 이어서 작업한다. 단, 노트 내용은 실제 파일과 대조해 확인한다.
- `.claude-memory/`가 있는 프로젝트에서는 의미 있는 작업 단위(기능 하나, 버그 하나)를 끝낼 때마다 progress.md에 기록한다.
  ```
  ### YYYY-MM-DD HH:MM · <작업 제목>
  - 변경: <주요 파일>
  - 확인: <테스트·실행 결과>
  - 메모: <남은 일, 주의점>
  ```
- 사용자의 결정과 선호는 대화에만 두지 말고 decisions.md에 기록한다.
  ```
  ## YYYY-MM-DD · <제목>
  - 결정: … / 이유: … / 대안: …
  ```
- `⚠ 컨텍스트 사용량` 경고가 보이면 현재 작업 단위를 마무리하고 사용자에게 `/session-save` 후 `/clear`를 제안한다.
- 압축 요약에는 반드시 넣는다: 진행 중인 작업, 아직 파일에 기록하지 않은 결정, 실패 중인 테스트와 원인 가설, 다음 단계.
